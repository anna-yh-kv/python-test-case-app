# Testfallsregister

Det här projektet är ett enkelt testfallsregister byggt i Python.

## Funktioner

- Registrera nya testfall.
- Visa alla registrerade testfall.
- Avsluta programmet.

## Information om ett testfall

Varje testfall innehåller:
- Titel
- Beskrivning
- Förväntat resultat

## Starta programmet

Öppna terminalen i projektmappen och skriv:

py app.py
